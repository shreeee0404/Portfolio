Online Hotel Booking System

Room Management | Customer Login | Admin Dashboard

Project Overview

A full-stack web application built using React.js, Node.js, Express, and SQL for efficient hotel and room management. This system allows administrators to manage rooms and customers to book rooms online seamlessly.

Features

  • Admin: Add, edit, view, and delete rooms with availability and pricing details.
  • Customer: Browse rooms, check availability, book and manage their reservations.
  • Secure login and signup system using JWT and password encryption.
  • Booking history and user dashboard for customers.
  • Responsive UI for mobile and desktop using React and Bootstrap.

Login Flow

Admin Login
  • Access via Admin credentials.
  • Redirects to the Admin Dashboard.
  • Admin can manage rooms (CRUD), view all bookings, and handle user data.
Customer Login / Signup
  • New users can register through the Signup Page.
  • Existing users can log in and access the Customer Dashboard.
  • Customers can browse available rooms, make bookings, and view booking status.

Tech Stack

  • Frontend: React.js, Bootstrap
  • Backend: Node.js, Express.js
  • Database: MySQL / SQL Server
  • Authentication: JWT, bcrypt
