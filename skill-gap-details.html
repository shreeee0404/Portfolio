Project Overview

About the Project

The AI-Powered Skill Gap Analysis and Career Recommendation System is an intelligent platform designed to help users understand their current skills and career opportunities.

Users can enter their skills manually or upload a PDF resume. The system analyzes the skills, predicts a suitable career role, calculates skill-match percentage, identifies missing skills, and provides personalized learning recommendations.

AI & Machine Learning

Techniques used in the project.

TF-IDF

Converts skill-related text into numerical feature representations for machine learning.

Random Forest

Predicts a suitable career role based on the user's skill profile.

Cosine Similarity

Compares user skills with career-role requirements to identify skill matches and gaps.
