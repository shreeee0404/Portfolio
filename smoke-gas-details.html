Smoke & Gas Detection System

An Arduino-based real-time safety system designed to detect smoke and combustible gases and provide immediate alerts.

Objective

The objective of this project is to develop a simple and reliable real-time detection system for identifying smoke and combustible gases using an MQ-2 gas sensor and Arduino. When the detected gas or smoke level crosses a predefined threshold, the system immediately activates an audible warning and displays the alert status on an LCD.

Project Overview

The Smoke & Gas Detection System continuously monitors the surrounding environment using an MQ-2 sensor. The sensor detects changes in smoke and combustible gas concentration and sends the readings to an Arduino microcontroller. The Arduino compares the sensor value with the configured threshold and activates the buzzer when a dangerous level is detected. An LCD provides the current monitoring status and warning information to the user.

Working Process

1

Sensor Monitoring
The MQ-2 sensor continuously monitors the surrounding environment for smoke and combustible gases.

2

Data Processing
The Arduino reads the sensor output and processes the detected gas or smoke level.

3

Threshold Detection
The measured value is compared with a predefined safety threshold.

4

Alert Generation
When the threshold is exceeded, the buzzer is activated to provide an immediate warning.

5

LCD Display
The LCD displays the current system status and corresponding warning message.

Technologies Used

Arduino MQ-2 Gas Sensor LCD Display Buzzer Embedded C/C++ IoT

Key Features

  • Real-time smoke and gas monitoring
  • MQ-2 based gas and smoke detection
  • Threshold-based danger detection
  • Immediate audible buzzer alert
  • LCD-based system status display
  • Arduino-based embedded implementation

Main Components

Arduino

Acts as the main controller and processes the sensor readings.

MQ-2 Sensor

Detects smoke and combustible gas concentration in the surrounding environment.

LCD Display

Displays system status and warning information to the user.

Buzzer

Produces an audible warning when dangerous smoke or gas levels are detected.

Applications

The system can be used for basic safety monitoring in homes, laboratories, workshops, kitchens, industrial environments, and other locations where early smoke or combustible gas detection is required.
