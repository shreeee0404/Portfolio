Interactive Online Yoga Academy

REST API-based platform for live yoga sessions, personalized plans, and video tutorials

GitHub Download PPT

Project Overview

The Interactive Online Yoga Academy is a REST API-based platform designed to provide users with interactive yoga learning experiences. The system supports user authentication, live sessions, personalized yoga plans, video tutorials, instructor feedback, and progress tracking.

Key Features

User Registration

Users can register and securely access the platform using JWT-based authentication.

Live Yoga Sessions

Provides integration with platforms such as Zoom and YouTube for live yoga sessions.

Personalized Plans

Creates personalized yoga plans based on user questionnaire responses.

Video Tutorials

Provides yoga tutorials categorized according to level and type.

Instructor Feedback

Supports instructor feedback to help users improve their yoga learning experience.

Progress Tracking

Tracks user progress throughout their yoga learning journey.

Technology Stack

Spring Boot REST APIs JWT Security MySQL Database

System Workflow

01. User Registration

Users register and authenticate securely using JWT-based authentication.

02. User Questionnaire

Users provide information through a questionnaire to support personalized yoga planning.

03. Personalized Yoga Plan

The system provides a yoga plan based on the user's responses.

04. Yoga Learning

Users access categorized video tutorials and participate in live yoga sessions.

05. Feedback & Progress

Instructor feedback and user progress are maintained through the platform.

Project Outcome

The Interactive Online Yoga Academy provides a centralized platform for online yoga learning with personalized plans, live sessions, categorized tutorials, instructor feedback, and progress tracking.
